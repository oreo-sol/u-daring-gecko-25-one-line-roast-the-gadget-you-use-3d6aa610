# One-Line Roast: The Gadget You Use Every Day

A single original roast line (84 characters) about the smartwatch that
congratulates its owner for standing up — as if sitting were the hard
part of the day.

> My watch congratulates me for standing up, like sitting was the hard part of my day.

## Files

- `entry.txt` — the text, written by `main.ts` (not stored in the repo)
- `main.ts` — writes the entry text to `$MAKEFUN_OUTPUT_DIR/entry.txt`
  (or `/output/entry.txt`), validating it is one line of 1–200 Unicode
  code points, then reads it back and verifies it
- `LICENSE` — MIT

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
